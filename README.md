# Set 3 - Tech Gadget Inventory Hub

A responsive React + Vite single-page application for registering and reviewing tech gadgets.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Suggested Git workflow (minimum four commits)

Run these steps in your own GitHub repository so the required incremental history appears under your account:

1. Commit project setup: `git commit -m "chore: initialize React Vite project"`
2. Commit the form: `git commit -m "feat: add gadget form and validation"`
3. Commit the table: `git commit -m "feat: add TanStack table and pagination"`
4. Commit details/filter styling: `git commit -m "feat: add active profile and category filters"`

Then push to GitHub and import the repository into Vercel. The Vite defaults are sufficient (`npm run build`, output directory `dist`).
